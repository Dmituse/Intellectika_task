# 3D Object Creator

Цель проекта — разработать прототип системы, которая позволяет создавать 3D-фигуры в Unity по текстовым командам. Пользователь или внешний сервис (например, Flask-сервер) отправляет команду в текстовом виде, а Unity интерпретирует её и создаёт соответствующий объект на сцене.

_Проект демонстрирует:_
Отправку текстовой команды на внешний сервер.
Получение ответа и разбор команды.
Динамическое создание 3D-фигур с указанными параме

_Как работает код:_
В методе Start() автоматически вызывается корутина SendTextCommand, которая отправляет команду на сервер:
StartCoroutine(SendTextCommand("Create a sphere with radius 3"));

Метод SendTextCommand(string command):
Преобразует команду в JSON: {"command":"..."}
Отправляет POST-запрос на Flask-сервер (http://localhost:5000/interpret)
Ждёт ответа
Если запрос успешен, получает результат и вызывает ExecuteCommand(result)

Метод ExecuteCommand(string command):
Проверяет тип фигуры (сейчас поддерживается только сфера)
Извлекает числовой параметр (radius) через ExtractFloatValue
Создаёт объект на сцене с помощью соответствующего метода (CreateSphere)

Пимер создания сферы:
GameObject sphere = GameObject.CreatePrimitive(PrimitiveType.Sphere);
sphere.transform.localScale = new Vector3(radius, radius, radius);
Масштабируется по всем осям на указанный радиус
В Unity scale влияет на размер объекта относительно исходного. Чтобы радиус реально соответствовал значению, необходимо умножать на 2 или использовать точный расчёт (например, делить исходный размер сферы на 2).

Метод ExtractFloatValue(string command, string parameter):
Находит параметр в строке команды
Берёт следующее слово и преобразует в число (float)
Если параметр не найден, возвращает 1.0

Если запрос успешен, получает результат и вызывает ExecuteCommand(result)****

# _Тестовое задание: _
создании прототипа системы в Unity, которая позволяет создавать 3D-фигуры по текстовым командам, отправленным пользователем или внешним сервером. Необходимо реализовать отправку команды на сервер, её интерпретацию и возврат с параметрами обратно в Unity, после чего движок должен распознавать тип фигуры, извлекать её параметры, такие как радиус, высота или ширина, и создавать объект на сцене с указанными характеристиками. Пример работы системы — создание сферы с заданным радиусом, при этом объект должен корректно отображаться и масштабироваться. Код должен быть написан на C# с использованием Unity, обеспечивать расширяемость для добавления других типов фигур и параметров, а также отображать информацию о созданных объектах в консоли Unity.
